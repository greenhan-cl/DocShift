# 服务端业务模块目录

业务模块将在后续阶段逐个落地，本轮不生成空实现。模块边界与依赖方向如下：

```text
用户与身份
  ├── 调用邮件模块
  └── 调用文件管理模块（头像）

Task
  └── 调用转换模块

转换
  ├── 调用文件管理模块
  └── 调用任务调度模块

结果管理
  ├── 调用 Task 模块进行所有权校验
  └── 调用文件管理模块进行预览、删除和导出

清理与审计
  └── 读取到期记录并调用文件管理模块清理
```

后续每个业务模块采用独立目录，并按 `controller / service / repository / model` 的职责拆分。模块之间通过应用服务接口协作，不直接修改其他模块的数据。
